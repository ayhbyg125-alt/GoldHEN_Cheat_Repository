# FN Menu Hider — Rectangle Profile

Visual rectangle configuration for the Fortnite Menu Hider GoldHEN plugin.

Controls:
- L1 + R1: open/close menu
- L1 + Down: arm/disarm rectangle
- Up/Down: select
- Left/Right: resize
- Square: toggle
- Circle: close
- X: untouched/pass-through

Default rectangle: X=0, Y=0, Width=320, Height=120.
Width range: 32–4096. Height range: 16–4096. Step: 16 pixels.

The rectangle is rendered by the button_swap PRX through the framebuffer path. This file records the profile; it is not a fabricated memory-cheat entry.

Target title: CUSA07669.
